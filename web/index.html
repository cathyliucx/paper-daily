研究兴趣

连接仓库后，可管理研究兴趣、模型和采集任务。

如何取得仓库授权令牌？

在 GitHub 创建 Fine-grained token，Repository access 选择 Only select repositories，仅选 paper-daily。Contents、Actions、Secrets、Variables 设为 Read and write，Metadata 保持 Read-only。有效期建议30天。

创建 GitHub 授权令牌 ↗
令牌仅供你本人管理仓库，刷新或断开后清除。分享网站链接不会携带令牌；不要分享令牌或已连接的浏览器会话。

已配置兴趣

    添加研究兴趣
    精确检索设置（可选）

    最多10个兴趣。保存到仓库后，自动按新配置采集最近7天的论文，保留现有论文缓存。

    模型配置

    连接 GitHub 仓库后，可读取配置状态并保存模型。

    保存后于下一次采集生效。保存成功不代表模型接口已连通；采集任务会实际调用并记录结果。保存不会自动运行采集或清理缓存。

    清理论文缓存并重新采集

    忽略历史论文缓存，按当前研究兴趣重新检索最近7天的每日论文，并重建顶会论文列表。研究兴趣和模型配置不会被删除。

    需要等待 GitHub 任务运行及发布。完成前保留现有页面；任务失败会显示原因，不会显示为清理成功。
